# 个人博客主页

一个轻量的个人网页：简洁卡片式布局 + 可真实播放的音乐播放器，支持白天/夜晚自动换肤、手机端自适应。

播放器固定 **3 首**歌，歌单直接写在 `script.js` 顶部，改起来就是改 3 行。

## 目录结构

```
person-site/
├── index.html          页面结构
├── styles.css          样式（含白天/夜晚两套配色）
├── script.js           交互逻辑（播放器 + 主题跟随）
├── avatar.jpg          头像图片
├── qr.png              二维码图片
├── start-server.bat    双击启动本地预览服务器（Windows）
├── .nojekyll           让 GitHub Pages 跳过 Jekyll 处理，不要删
└── music/              音频文件夹（当前 3 首）
    ├── DJ舒心 - 嘉宾（DJ舒心版）.mp3
    ├── DJ阿轩 - 偏爱 (咚鼓版).mp3
    └── 阿泽 - 够爱（DJ版）.mp3
```

## 快速开始

### 本地预览（推荐）

**Windows**：直接双击 `start-server.bat`，会自动开服务器并打开浏览器。

**手动启动**：在本文件夹下开一个本地服务器：

```bash
python -m http.server 8000     # 方式一：Python
npx serve .                    # 方式二：Node
```

然后浏览器打开 `http://localhost:8000`。

> 也可以直接双击 `index.html` 打开，但部分浏览器在 `file://` 协议下会拦截本地音频。**音乐不播放就改用本地服务器方式。**

## 换歌

打开 `script.js`，改最上面的 `SONGS` 数组：

```js
const SONGS = [
  { name: "嘉宾（DJ舒心版）", artist: "DJ舒心", file: "DJ舒心 - 嘉宾（DJ舒心版）.mp3" },
  { name: "偏爱（咚鼓版）",   artist: "DJ阿轩", file: "DJ阿轩 - 偏爱 (咚鼓版).mp3" },
  { name: "够爱（DJ版）",     artist: "阿泽",   file: "阿泽 - 够爱（DJ版）.mp3" },
];
```

三个字段的含义：

| 字段 | 说明 |
|---|---|
| `name` | 歌名，显示用，随便写，不影响播放 |
| `artist` | 歌手，显示用，同上 |
| `file` | **只写文件名**，不用带 `music/` 前缀。必须和 `music/` 里的实际文件名完全一致 |

换歌步骤：把新音频放进 `music/` → 把 `file` 改成新文件名 → 刷新页面。

想改成 4 首、5 首也可以，照着格式往下加就行，播放器会自动适配。

> **关于中文文件名**：脚本已经自动做了 URL 转义，中文、空格、全角括号都不用你操心，照抄文件名即可。

## 部署到 GitHub Pages

这是纯静态站点（无构建步骤、全部相对路径），可以直接托管。

### 网页上传（不用装 Git）

1. GitHub → 右上角 **+ → New repository**，仓库名填 `person-site`，选 **Public**，创建
2. 仓库页点 **Add file → Upload files**
3. 把 `person-site` 文件夹**里面的所有内容**拖进浏览器（直接拖文件夹会保留 `music/` 结构）
4. 填提交信息 → **Commit changes**
5. **Settings → Pages** → Source 选 **Deploy from a branch** → Branch 选 **main** + **/(root)** → **Save**
6. 等 1～2 分钟，访问 `https://你的用户名.github.io/person-site/`

### Git 命令行

```bash
cd person-site
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin https://github.com/你的用户名/person-site.git
git push -u origin main
```

### 要注意的点

- 仓库体积约 **11.7 MB**，文件共 **9 个** —— 远低于 GitHub「单文件 25 MiB、建议 1 GB」的限制，一次拖完即可
- `.nojekyll` 让 GitHub Pages 跳过 Jekyll，避免中文文件名出问题，**不要删**
- 线上改歌：直接在网页上编辑 `script.js` 顶部那 3 行，或在 `music/` 里传新文件后改 `file`
- Git 会永久保留历史，以后删歌仓库也不会变小（这个体量完全无所谓）

## 换其他内容

### 头像 / 二维码

用同名文件覆盖 `avatar.jpg`、`qr.png` 即可（建议尺寸：头像 200×200，二维码 240×240）。

### 文字

打开 `index.html` 直接改：

| 位置 | 对应内容 |
|---|---|
| 顶部标题卡 | 「这是我的个人博客」 |
| 左侧卡片 | 我的简介 / 个人说明 / 联系方式 |
| 右侧卡片 2、3 | 励志语录、备用内容 |
| 底部通栏 | 版权信息 |

### 配色

打开 `styles.css`，白天主题在 `:root`，夜晚主题在 `[data-theme="dark"]`：

```css
:root {
  --bg: #f2f3f5;        /* 页面底色 */
  --card: #ffffff;      /* 卡片底色 */
  --text: #1a1a1a;      /* 主文字 */
  --active-fg: #2f6bff; /* 主题色（选中、播放器等） */
}
```

## 功能一览

### 音乐播放器
- 播放 / 暂停、上一首 / 下一首
- 点击列表任意歌曲即播放
- 进度条可拖动跳转，显示当前时间和总时长
- 列表自动显示每首歌的真实时长
- **音量控制**：拖动音量条调节，点击喇叭图标一键静音
- **随机播放**：开启后下一首随机跳转（不重复当前曲）
- **单曲循环**：开启后一曲播完自动重播
- 一曲播完自动播放下一首
- **记忆**：记住音量和上次听到哪首，下次打开自动选中（不自动播放）
- **系统媒体控制**：手机锁屏 / 通知栏显示歌名歌手，支持耳机线控
- **缓冲提示**：加载慢时播放按钮会转圈，不会以为点了没反应
- 快捷键：空格键 = 播放 / 暂停

### 主题
- 自动跟随系统：系统深色 → 夜晚模式，系统浅色 → 白天模式
- 换设备、换时段都自动适配，无需操作

### 响应式
- 桌面：左侧简介 + 右侧三张卡片
- 手机：自动变单列堆叠，播放器保持左列表 / 右播放器并排

## 常见问题

**Q：点播放没声音？**
A：① 建议双击 `start-server.bat` 用本地服务器打开（`file://` 下部分浏览器会拦截本地音频）；② 确认 `SONGS` 里的 `file` 和 `music/` 里实际文件名完全一致（空格、全角/半角括号、大小写都要对上），按 F12 看 Console 是否报 404。

**Q：能自动播放吗？**
A：不能。所有现代浏览器都禁止页面在用户交互前自动出声，必须点一次播放按钮，这是通用限制。

**Q：歌曲时长一开始显示 `--:--`？**
A：页面在后台逐个读取音频的元数据，读完就会显示，通常一瞬间。文件大或网络慢时会稍慢一点，不影响播放。
